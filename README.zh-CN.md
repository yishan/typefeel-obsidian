# 字感 · Obsidian 插件

[English](README.md) | **简体中文**

在 Obsidian 中练习中文、粤语和英文打字。使用自己的输入法，练习文本可以来自自己的笔记。

源码来自 [typefeel](https://github.com/yishan/typefeel)，与 [typefeel.app](https://typefeel.app) 网页版、DSH 插件共用同一份练习源码。

## 功能

- **练习**：15／30／60 秒限时，或短篇／中篇／长篇。当前输入行固定，前后文字逐渐淡出。
- **落字游戏**：中文单字和词语从上方落下，用输入法上屏完整目标即可消除。
- **用笔记练习**：选择笔记库中的文件夹，从其中的笔记选取段落；也可以直接练习编辑器中选中的文字。
- **注音与手感**：全拼、粤拼和双拼提示，光标样式，真实键盘录音音效。
- **本地记录**：最佳成绩、最近练习和游戏成绩只保存在本机。
- 界面语言（中文或英文）和明暗主题跟随 Obsidian。

## 使用

- 点击侧边栏的键盘图标，或在命令面板中运行「打开打字练习」「打开落字游戏」。
- 用自己的笔记练习：在「设置 → Type Feel → 笔记文件夹」或字感设置对话框中添加文件夹，再把语料来源切换为「我的笔记」。添加文件夹之前不会读取任何笔记。
- 练习笔记中的一段：选中文字，在命令面板或编辑器右键菜单中选择「用选中内容练习打字」。

命令没有默认快捷键，可以在「设置 → 快捷键」中自行绑定。

练习时按 `Esc` 重练当前文本。游戏中按 `Esc` 或 `Cmd/Ctrl+P` 暂停：游戏进行中且焦点在游戏内时，`Cmd/Ctrl+P` 只暂停游戏，不打开命令面板；暂停后再按会照常打开命令面板。输入法组字时，按键交给输入法处理。

## 隐私

- 不联网，不发出任何请求，不收集数据。
- 只在本机读取你选定文件夹中的笔记，只用于选取练习文本，不保存、不上传笔记内容。
- 成绩只记录段落指纹，不记录笔记路径或正文。
- 偏好和成绩保存在本机 Obsidian 的本地存储中，同一设备上的笔记库共用，不随笔记库同步。文件夹列表按笔记库分别保存在插件的 `data.json` 中。

## 安装

插件处于测试阶段，请用 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 安装，仓库地址填 `yishan/typefeel-obsidian`。需要 Obsidian 1.8.7 或更新版本。

手机端尚未测试。
